## Portfolio Overview

This repository contains the complete three-part database system project for **SwiftCart**, covering everything from initial conceptual design to live PostgreSQL implementation and advanced security administration.

### Navigation

* [Portfolio Activity 1: Database Design & Specification](./portfolio-1-database-design)
  * Business description, Crow's Foot ERD image, PostgreSQL DDL schema, and 3NF normalization analysis.
* [Portfolio Activity 2: Database Implementation, Data Population & Querying](./portfolio-2-database-implementation)
  * Sample dataset population scripts, complex analytical queries (JOINs, CTEs, Window Functions), and execution report.
* [Portfolio Activity 3: Advanced Database Concepts & Security Administration](./portfolio-3-database-administration)
  * Indexing strategy, query performance tuning (`EXPLAIN ANALYZE`), Role-Based Access Control (RBAC), Row-Level Security (RLS), and ACID transaction management analysis.
