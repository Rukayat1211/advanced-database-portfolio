# Portfolio Activity 1: Database Design & Specification

## Executive Summary
This folder contains the complete conceptual, logical, and physical database design for **SwiftCart**, a simulated multi-vendor e-commerce platform.

---

## Deliverables Included

1. **`01_organisation_description.md`**  
   Detailed business scenario, target system users, core entities stored, and supported transactions.

2. **`02_er_diagram.png`**  
   Entity-Relationship Diagram representing the relational structures, primary/foreign keys, and cardinalities between entities.

3. **`03_schema_ddl.sql`**  
   Production-ready PostgreSQL DDL script creating all database tables, constraints (`NOT NULL`, `UNIQUE`, `CHECK`), and referential integrity rules (`FOREIGN KEY`).

4. **`04_normalisation_explanation.md`**  
   Mathematical functional dependency breakdown proving 3rd Normal Form (3NF) compliance to eliminate data redundancy.
