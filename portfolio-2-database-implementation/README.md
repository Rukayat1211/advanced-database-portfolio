# Portfolio Activity 2: Database Implementation, Data Population & Querying

## Executive Summary
This folder contains the practical database implementation, dataset seed scripts, and complex analytical queries for **SwiftCart**, executing against the PostgreSQL schema established in Portfolio Activity 1.

---

## Deliverables Included

1. **`01_data_insertion.sql`**  
   Data insertion script populating all 7 relational tables with realistic sample data, maintaining strict referential integrity and foreign key order.

2. **`02_complex_queries.sql`**  
   Production-ready analytical SQL queries demonstrating multi-table `JOIN`s, aggregations (`GROUP BY`, `HAVING`), Common Table Expressions (CTEs), window functions (`DENSE_RANK`), and conditional business logic (`CASE WHEN`).

3. **`03_query_execution_report.md`**  
   Detailed analytical breakdown explaining query objectives, performance logic, expected results, and business intelligence outcomes.
