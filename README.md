## Portfolio Overview

This repository contains the complete five-part database system project for **SwiftCart**, covering initial conceptual design, relational query optimization, transaction concurrency control, NoSQL document modeling, and distributed/cloud architecture.

### Navigation

* [Portfolio Activity 1: Database Design & Specification](./portfolio-1-database-design)
  * Business description, Crow's Foot ERD image, PostgreSQL DDL schema, and 3NF normalization analysis.
* [Portfolio Activity 2: Database Implementation & Query Optimisation](./portfolio-2-database-implementation)
  * Sample dataset population scripts, complex analytical queries (JOINs, CTEs, Window Functions), and execution report.
* [Portfolio Activity 3: Advanced Database Concepts, Transactions & Security](./portfolio-3-database-administration)
  * Indexing strategy, query performance tuning (`EXPLAIN ANALYZE`), Role-Based Access Control (RBAC), Row-Level Security (RLS), and ACID transaction management analysis.
* [Portfolio Activity 4: NoSQL & Advanced Data Models](./portfolio-4-nosql)
  * MongoDB document schema validation, CRUD operations, aggregation pipelines, and dynamic catalog modeling technical report.
* [Portfolio Activity 5: Distributed & Cloud Database Exercise](./portfolio-5-distributed-cloud)
  * Multi-region topology design, horizontal hash partitioning (sharding simulation), replication health monitoring, and distributed transaction consistency.
